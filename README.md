# Week 3: Unsupervised Learning & Model Evaluation

**Student:** Binnala Esikha

## Project overview
This educational project demonstrates K-Means and Hierarchical (Agglomerative) clustering, PCA dimensionality reduction, cross-validation, confusion matrix, precision, recall, F1-score, ROC-AUC, and hyperparameter tuning with GridSearchCV.

## Files
- `week3_unsupervised_evaluation.py` — Python implementation
- `student_learning_dataset.csv` — small illustrative sample dataset
- `requirements.txt` — required Python packages
- `Week3_Report.docx` — project report

## Run
1. Install Python 3.
2. Install dependencies: `pip install -r requirements.txt`
3. Keep the CSV file in the same folder as the Python file.
4. Run: `python week3_unsupervised_evaluation.py`

Note: The dataset is a small illustrative learning sample, not a real student record dataset. Metrics can vary with the train/test split and are intended for demonstration, not real-world conclusions.
